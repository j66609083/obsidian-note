### 标量类型
1. 整数类型
	1. 整数溢出
		1. 调试模式下编译时，会包含整数溢出的检查，如果发生溢出，程序会以错误退出
		2. 发布模式下编译时，不会包含整数溢出的检查，如果发生溢出，会执行补码回绕。超出类型所能存储的最大值的值会回绕到该类型所能存储的最小值
			1. `wrapping_*`方法
			2. `checked_*`方法
			3. `overflowing_*`方法
			4. `saturating_*`方法
	2. 有符号整数
		1. 使用二进制补码表示法（two's complement representation）
		2. 取值范围：−2^(n − 1) to 2^(n − 1) − 1
	3. 无符号整数
		1. 取值范围：0 to 2^n − 1
2. 浮点类型
	1. 根据 IEEE-754 标准进行表示
3. 数值操作
	1. 除法
		1. 不同语言表现不一样
```rust
// Rust
// 整数相除还是整数，向零的方向取整
fn main(){
   let mut truncated = -5 / 3; // Results in -1
   let mut truncated = 5 / 3; // Results in 1
}
```

```python
# python 3.14版本
# 整数相除是浮点数，想取整需要用特殊写法
a = -5 / 3  # 结果是-1.6666666666666667
a = 5 / 3  # 结果是1.6666666666666667

# 整数相除取整，向下取整
a = -5 // 3 # 结果是-2
a = 5 // 3  # 结果是1
```
